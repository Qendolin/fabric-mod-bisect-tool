# Translation Rules

- Use the informal form (for German `du`, `dein`, `deine`, and the corresponding verb forms).
- Keep the application name `Mod Bisect Tool` unchanged in every language.
- Keep mod IDs, file names, paths, version predicates, and other technical values unchanged.
- Preserve template variables such as `{{.Path}}`, `{{.Version}}`, and `{{.Error}}` exactly.
- Preserve intentional paragraph breaks and line breaks unless the target language requires a different layout.
